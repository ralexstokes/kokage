# kokage-supervisor

This is a pre-release marker for the structured task supervision crate in
[Kokage](https://github.com/ralexstokes/kokage/issues/245), an actively
developed library for OTP-style supervision trees and typed actors.

Version `0.0.0` intentionally exposes no API. Do not depend on this release;
the first usable release will follow the package rename described in the
tracking issue.
