# kokage-console

This is a pre-release marker for the experimental web console in
[Kokage](https://github.com/ralexstokes/tokio-otp/issues/245), an actively
developed library for OTP-style supervision trees and typed actors.

Version `0.0.0` intentionally exposes no API. Do not depend on this release;
development status and future availability are tracked in the linked issue.
